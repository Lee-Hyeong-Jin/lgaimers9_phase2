# 솔루션 요약 (Phase 3 코드/PPT 제출용 초안)

## 1. 문제 정의와 핵심 관찰
- 투구 단위 제구 성공 확률 예측, Brier Skill Score(BSS). 신호가 매우 약함(베이스라인 BSS 0.55%) → **평균(레벨) 캘리브레이션 오차 δ의 비용 = δ²/0.25**가 지배적.
- `asof_*` 누적률은 2019년부터의 **정확한 누적 평균** → 각 행의 `asof_n × asof_rate − 학습 데이터 누적 합`으로 **투수·타자의 당해 시즌 현재까지 성공률/실패유형률/구종 구성**을 행 단위로 정확 복원 (규칙: 행 자체 입력 + 공식 학습데이터 통계).
- 시즌 드리프트(0.565→0.486)와 **퓨처스(F) 측정체계 변화(2023년, 0.70→0.47)**, 팀 13 고유 레짐 → 시즌 인식 모델 필수. 행 단위 증거로 리그 레벨 변화의 ~15%만 적응 가능 → 나머지는 사전(추세) 베팅.
- 연속 행의 누적률 차분으로 학습 투구의 실패 유형(반대/가운데/이탈)·볼/스트라이크·구종군을 복원 → **다중클래스 학습 타겟**(추론 입력 아님).

## 2. 검증 설계
- 시계열 폴드: 2019~2023 → 2024 (주), 2019~2022 → 2023 **R(1군) 경기 한정**(F 레짐 변화 배제) (보조).
- "오라클 shift" 점수(평균을 정답에 맞춘 뒤의 점수)로 판별력과 레벨을 분리 평가.
- LB 매핑: 폴드 raw ~850 → LB 1062; 폴드 이득의 약 50~100%가 LB로 전이.

## 3. 피처 (모두 행 단위 + 학습 데이터 통계)
- 원본 상황 피처, 카운트 상태, 플래툰, 홈/원정.
- 분해 피처: 시즌 현재(cur) n/성공률/reverse/middle/ball/strike/구종 비율, 과거 시즌(prior) 누적률, 직전 시즌, 시즌 수·공백, 수축(shrinkage) 추정치, 변화량, 최근 폼(prev1/3/5 − cur).
- 투수 구종별 성공률 prior, 퓨처스 신체계(2023~) prior, 투수×타자 맞대결 prior, 투수 역할(선발 비율·경기당 투구수).
- Trackman: 경기 지문(inning·초말·카운트·아웃·좌우) 멀티셋 유사도로 87% 경기 매칭 → 투수 ID 크로스워크(순도 99.6%) → 구속/회전/무브먼트/릴리스 일관성/구종 구성(행 시즌 이전 시즌만).

## 4. 모델과 앙상블
- LightGBM **다중클래스**(성공/반대/가운데/이탈) 8시드, 최근 시즌 지수 가중(0.15) — 이진 대비 폴드 +45.
- CatBoost MultiClass + 투수/타자 ID 범주형(CTR), lr 0.02×2500 — 단일 모델 최강(폴드 921).
- CatBoost MultiClass(ID 미사용). (멀티태스크 MLP는 폴드에서 +8이었으나 LB에서 기여 없음(v11 1107 vs v15 1109)으로 최종 제외.)
- logit 가중 블렌드 + 학습 데이터 추세 기반 상수 shift(−0.005): LB 역산(v3/v10s)으로 δ≈+0.004~0.005 확인.
- 콜드스타트 투수(과거 시즌 투구 0) 행은 모델이 과소확신(폴드 십분위 기울기 1.22) → 해당 행의 logit을 학습 상수 중심(0.486) 기준 1.15배 확장하는 행 단위 보정(폴드 +5.5).

### 4-1. 투수 잠재 수준의 동적 베이즈 추정 → 오프셋(init_score) (08-27 추가, 핵심 개선)
- 투수별 시즌 편차 d_s = θ_s − μ_s를 상태로 두는 상태공간 모델: d_s = a·d_{s−1} + ε (τ²), 시즌 내 관측은 이항(정규 근사). 하이퍼파라미터(a=0.6, τ²=0.004, v_new=0.004)는 2020~23 예측 Brier로 적합.
- 각 행은 **자기 행의 시즌 현재 누적(n, s)** 과 **학습 데이터의 과거 시즌 합계**만으로 사후평균을 계산(행 독립).
- 사후평균을 피처로 넣으면 무효였지만, **부스팅의 init_score(이진: logit(pm), 다중클래스: 클래스별 log 사전)** 로 넣으면 트리가 "수준 대비 편차"만 학습 → 이진 862→900(+38), 다중클래스 921→934(+13), 블렌드 3폴드 평균 821→838.
- 같은 오프셋을 멀티태스크 MLP에 적용(클래스 로짓에 베이즈 로그사전 가산)하면 NN도 821→879(+57), 2023R 676→776으로 개선되어 블렌드 멤버로 유효(v18 후보, 가중 .15).
- 해석: 절대 확률을 직접 적합하는 트리는 시즌·투수 수준을 분할로 흉내내야 하지만, 오프셋은 이를 해석적으로 제거해 잔여 신호 학습에 용량을 집중.

## 08-28 밤: 투수×상황 차등 prior (CTX 피처)
- 잔차 분석: 최적 블렌드의 잔차에서 투수 전체 수준은 완전 흡수(전·후반 상관 −0.03)되었으나, 투수별 (vs좌타 − vs우타) 차등은 +0.31, 2스트라이크 차등은 +0.26의 지속성이 남아 있었음(37개 상황 전수 스캔에서 플래툰이 유일하게 큰 지속 신호).
- 구현: 사전 시즌 합계로 (해당 손 성공률 − 반대 손 성공률), (2K 성공률 − 비2K 성공률)을 유효표본 ne/(ne+1000)으로 축소한 특성(CTX_hand_diff/adj, CTX_2k_diff/adj). 행의 상황에 맞춰 부호화하며, 학습 통계만 사용(행 독립성 유지).
- 효과(로컬): LGB 오프셋 3폴드 평균 +7.3, CatBoost-ID fold 2024 +18.5(3시드), 블렌드 fold 2024 +9.6. NN에는 역효과(−16) → NN 멤버는 CTX 미사용.
- 제출본: v25(LGB-CTX 교체), v26(LGB-CTX + CatBoost-CTX). LB 미측정.

## 08-27 밤 2부: 라벨 출처 체제(LG 관여 경기) 발견
- 데이터 구조: F 행은 모두 LG 2군 경기(팀 id 13 관여 100%), R 행은 전 구단 경기. LG가 관여한 R 경기의 라벨 편차(양 팀 투수 모두)가 2019~2022 −.08~−.03에서 2023~2024 +.04로 반전했고, 같은 해에 F 리그 성공률도 .70→.49로 바뀜 → LG 측 라벨링 과정 변경으로 해석. 잠실을 공유하는 두산 경기에는 없는 효과라 구장 효과가 아님.
- 결과: 기존 최적 블렌드는 2024 LG 경기를 모든 투수에 대해 ≈+.016~.019 과소예측(소스별 시프트 상한 +24.6). 이것이 fold 2023(반전 해)에서 적응형 오프셋이 유리하고 ID 모델이 불리했던 이유이며, LB(2025)에서 ID 모델이 폴드보다 크게 전이되는 현상의 유력한 설명.
- 조치: 행 자체 입력만 쓰는 합법 피처 `LG_game`(팀 id 13 관여), `LG_regime`(LG_game × 시즌≥2023) 추가 → LGB 오프셋 940.3→954.1, CatBoost-ID(1시드) 928.8→940.2. 4개 멤버 재학습 = v29.
- 주의: 2025 라벨이 2023~24 체제를 따른다는 가정. v29 vs v27의 LB 차이가 이 가정의 실측.
