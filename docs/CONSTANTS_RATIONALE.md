# 상수(후처리 보정값) 산출 근거 — 코드 검증 소명 자료

대상 제출물: `submit_v48_lg30.zip` (LB 1224, 최고점) / `submit_v57_lg30_105.zip` / 그 이전 v33~v41.
모든 상수는 `model/ensemble.json`에 고정된 값이며, 추론 스크립트는 **각 행의 자기 컬럼(팀 ID, 경기 유형, 볼·스트라이크 카운트)에 상수를 더할 뿐** 평가 데이터의 다른 행·행 수·평균·분포를 어디서도 계산하지 않는다
(검증: 단일 행만 넣은 예측 = 전체를 넣은 예측, 차이 2.5e-10; `experiments/strict_audit2.log`).
아래는 각 상수가 **어떤 학습 데이터 관찰에서 나왔는지**, 그리고 리더보드 점수를 어느 범위까지 참고했는지를 있는 그대로 적은 것이다.

## 0. 적용 위치 (script.py, `main()` 말미)
```
p = blend(logit 가중평균)                       # 4개 멤버
p = p + prob_shift                               # 전역 레벨 (−0.004)
p = p + lg_shift   if 행이 LG(팀 13) 관여 KBO(R) 경기   # +0.015
p = p + lg30_shift if 위 행이면서 볼 3·스트라이크 0     # +0.09 (v48) / +0.105 (v57)
p = clip(p, 0.001, 0.999)
```

## 1. `prob_shift = −0.004` (전역 레벨)
| 근거 종류 | 내용 |
|---|---|
| 학습 데이터 | fold 2024(2023년까지 학습 → 2024 예측)에서 최종 구성 멤버의 평균 예측이 실제 평균(0.4861)보다 높음: lgb_mc_off 0.4885 / lgb_bin_off 0.4900 / Bayes 레벨 0.4923 → 최적 전역 shift ≈ −0.003~−0.004 (LOG 08-26 "레벨 점검"). 초기 모델의 폴드 최적 shift는 −0.012(같은 부호, 더 큼) → 보수적으로 −0.004 채택. v23/v24 폴드 평균 예측도 v15 대비 −0.0004/−0.0001로 동일 값 유지 적절. |
| 리더보드 참고 | 초기 2회 비교: v2(0) 1062 → v3(−0.007) 1071; v10(−0.005) 1108 vs v10s(−0.008) 1102. 학습 추정과 같은 방향·크기. 08-26(v17) 이후 −0.004로 고정, 이후 변경 없음. |

## 2. `lg_shift = +0.015` (LG 관여 KBO 경기 행)
### 2-1. 학습 데이터에서 관찰된 사실 (모두 train.csv 라벨 통계)
- LG(팀 ID 13)가 관여한 R 경기(홈·원정, 양 팀 투수 모두)의 성공률 편차(LG − 비LG): 2019 −.078 / 2020 −.059 / 2021 −.015 / 2022 −.033 / **2023 +.041 / 2024 +.039**. 다른 9개 팀의 관여 효과는 ±.02 이내. 잠실을 함께 쓰는 두산 경기에는 없음 → 구장 효과가 아님.
- 월별 궤적: 2023년 4월 −.022 → **5월 +.047** → 6~10월 +.063~+.090; 2024년 3월 +.052, 4~7월 +.040~.065, 8월 +.041, 9월 +.031.
- F(퓨처스) 행은 100%가 팀 13 관여 경기이고, F 성공률도 2023년에 .70 → .49로 반전 → 같은 해의 같은 사건(LG 측 라벨링 과정 변경)으로 해석.
- 이 관찰로 만든 피처 `LG_game`(팀 13 관여), `LG_regime`(2023년 5월 이후 LG 관여)이 fold 2024에서 +13.6~+51점. 팀 13이 LG라는 명칭은 설명용이며 모델은 ID 값만 사용한다. 외부 자료(구단 발표, ABS 도입 등)는 사용하지 않았다.
### 2-2. 크기 근거
- LG 피처가 없는 모델은 fold 2024의 LG-R 행을 **+.0164** 과소예측(잔차; 단순 시프트 +.015만으로 폴드 +20.6). stats의 소스별 효과(src_eff 2024): LG +.0428 / 비LG −.0062 / F −.0268.
- 최종 모델은 2019~2022(구체제, 음의 편차) LG 이력을 가중 .3~.74로 함께 학습하므로 2025 LG 행을 계속 과소예측할 가능성이 학습 데이터만으로도 예상됨. 적용값 +0.015는 위 학습 잔차 +.0164 이내.
### 2-3. 리더보드 참고 (있는 그대로)
- 동일 모델(v33)에 LG 상수만 다른 후보 3개를 제출해 비교: −0.005 → 1184, +0.010 → 1207.2, +0.015 → 1207.8 (v33 1195). 이 비교로 +0.015를 채택했다.
- 주의할 점: LG 피처를 포함한 v33 자체의 fold 2024 LG-R 잔차는 −.0074였다(피처가 2024를 흡수). 따라서 +0.015의 **크기**는 학습 범위 [0, +.0164] 안에 있지만 후보 3개의 리더보드 비교에 의존한 값이다. 주최측 답변(08-12, 08-19: "학습 범위 내 후보값을 2~3회 비교·보간하는 것은 허용")에 해당하는 수준이며, 그 이후 LG 상수를 다시 바꾼 제출은 없다.

## 3. `lg30_shift` = +0.09 (v48) / +0.105 (v57) — LG 관여 KBO 경기의 3-0 카운트
| 근거 종류 | 내용 |
|---|---|
| 학습 데이터 | 2023.5~2024 LG-R 행의 3-0 카운트 성공률 **.598**(2023H2 .601 / 2024H1 .615 / 2024H2 .628; 구체제 2019~22는 .43~.49) vs LG-R 전체 .543. 비LG 3-0은 .468(전체 .486)로 초과 효과 없음. F(LG 2군) 3-0도 효과 없음(.526). 성공 정의 분해: 3-0에서 P(성공\|스트라이크) LG .677 vs 비LG .502. LG 과정 특이 셀 44개 전수 스캔에서 3-0만 유의(z 4.2). |
| 모델 잔차 | v33 fold 2024 잔차 LG-R∧3-0 = **+0.105**(590행); 멤버별 LGB +.094 / CatBoost +.110 / NN +.107 / NN-ID +.107 (모든 멤버가 놓침 → 사후 규칙이 상보적). 규칙 +0.08/+0.10/+0.12 → 폴드 +9.6/+10.2/+10.0. 2024 전반을 학습에 넣어도 잔차 +0.107(불변). 투구 측/타격 측 대칭. |
| 채택값 | v48: 0.09(잔차의 보수적 축소). v57: 0.105(폴드 잔차값 그대로). **리더보드로 크기를 정하지 않았다.** v48 결과(1224)로부터 더 큰 값(0.14)을 역산할 수 있었으나 학습 근거를 벗어나므로 제출하지 않았다. |

## 4. 블렌드 가중치 (.25 / .35 / .10 / .30)와 멤버 구성
fold 2024 OOF 최적화(LOG "오프셋 블렌드 3폴드", "v33 fold-2024 추정")로 결정. 가중 변형(v37)은 LB 중립(1195 = v33)이어서 LB로 조정하지 않았다.
