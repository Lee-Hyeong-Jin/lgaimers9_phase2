# 솔루션 PPT 개요 (Phase 3 제출용 초안)

1. 문제 이해 — 제구 성공 확률 예측, Brier Skill Score의 특성(평균 캘리브레이션 비용 δ²/0.25), 신호가 약한 문제
2. 데이터 발견 — asof 누적률의 정확한 분해(시즌 현재 vs 과거), 실패 유형 복원, 시즌 드리프트·퓨처스 측정체계 변화(2023)·팀 레짐
3. 검증 설계 — 시계열 폴드(2019~23→2024, 2019~22→2023 R전용), 오라클 shift로 판별력/레벨 분리, 폴드→LB 전이 기록
4. 피처 — 분해 피처, 최근 폼, 구종별/퓨처스 신체계/맞대결 prior, Trackman ID 크로스워크(경기 지문 매칭)
5. 모델 — 다중클래스 목적함수(+45), CatBoost MultiClass+ID CTR(lr 0.02×2500), 최근 시즌 가중, logit 블렌드, 상수 shift(−0.005, LB 역산 δ≈0.004)
6. 규칙 준수 — 행 단위 추론 설계, 단일행/셔플/전체 동일성 검증, 학습용 함수와 추론 경로 분리
7. 실패 기록 — HP/DART/12클래스/NN/세그먼트 재보정/2단계 추정기/Trackman 피처 등 (왜 안 됐는지)
8. 상한 분석 — 투수 시즌 수준 누설 실험(+300) → 현실적 상한 추정, 남은 병목
9. 재현 — reproduce.sh, 환경(ENV.md), 실행 시간(24.5만 행 ~33초)
