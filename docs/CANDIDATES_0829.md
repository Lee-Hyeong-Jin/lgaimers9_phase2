## 근거 요약
- 폴드→LB 전이(실측): ID 학습 멤버(CatBoost-ID/NN-ID)는 폴드 이득의 ~1.5~2배 전이, 오프셋 LGB 교체(v17)는 폴드 +16 → LB −5 (잡음 SE ≈ 5 → 실제 실패). 캘리브레이션류(cold slope/sharpen/shift 추가)는 전이 0 이하.
- 새 신호(로컬 검증): 투수×타자손(플래툰)·투수×2스트라이크 차등 prior(CTX 피처). LGB 오프셋 3폴드 (717.1/816.7/940.3 vs 718.2/800.2/933.9), 블렌드 3폴드 모두 +3~4.
